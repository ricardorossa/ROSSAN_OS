Sobre o ROSSAN

ROSSAN OS é um sistema operacional experimental independente de 32 bits para arquitetura x86, totalmente brasileiro, desenvolvido inicialmente em 2004 em Joinville-SC por Ricardo Rossa, distribuído como uma imagem de disco pronta para instalação em hardware compatível ou execução em emuladores.

Máquina física

  1. Grave a imagem em um pendrive usando uma ferramenta como Rufus.
  2. Reinicie o computador.
  3. Acesse o menu de boot da BIOS.
  4. Selecione a mídia que contém o Rossan.
  5. Aguarde a inicialização.

Requisitos

  • Hardware x86 compatível
  • Boot pelo BIOS
  • Pendrive com imagem de distribuição

Compatibilidade com equipamentos específicos pode variar.

Executar no QEMU

Requisitos: QEMU instalado no Windows e o arquivo .img da distribuição.

Execute no PowerShell:

qemu-system-i386 -m 64 -rtc base=localtime -drive file="rossan-boot-fat32-superfloppy.img",format=raw,if=ide -boot order=c

Também é possível utilizar softwares de virtualização compatíveis com discos RAW, desde que permitam inicialização por BIOS.
