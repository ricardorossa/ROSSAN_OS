ROSSAN OS é um sistema operacional experimental de 32 bits, totalmente brasileiro, desenvolvido inicialmente em 2004 em Joinville-SC por Ricardo Rossa, distribuído como uma imagem de disco pronta para instalação em hardware compatível ou execução em emuladores.

Como instalar

Baixe a imagem oficial do Rossan32 disponível nas releases do GitHub do projeto.

Uma imagem preparada pode ser fornecida no formato:

rossan-boot-fat32-superfloppy.img

Essa imagem já contém:

  • Boot loader
  • Kernel Rossan32
  • Interface gráfica
  • Configuração
  • Aplicativos
  • Ícones e recursos visuais

Não é necessário compilar ou configurar arquivos-fonte.

Máquina física

  1. Grave a imagem em um Pendrive usando uma ferramenta como Rufus.
  2. Reinicie o computador.
  3. Acesse o menu de boot da BIOS.
  4. Selecione a mídia que contém o ROSSAN.
  5. Aguarde a inicialização do sistema.

Como executar no QEMU

Requisitos:

  • QEMU instalado no Windows
  • Arquivo .img da distribuição ROSSAN

Com a imagem FAT32:

qemu-system-i386 -m 64 -rtc base=localtime -drive file="rossan-boot-fat32-superfloppy.img",format=raw,if=ide -boot order=c

Também é possível abrir a imagem em um software de virtualização compatível com discos RAW, desde que ele permita inicialização por BIOS.
